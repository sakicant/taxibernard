# taxivodice.hr

Website for **TAXI Vodice Bernard** (taxivodice.hr), a private taxi and
transfer service run by Bernard Mikulić in Vodice, Croatia. Rebuilt from the
previous WordPress + CabGrid site into a static site with a custom PHP
booking backend, replacing CabGrid.

Static site generated by `build.py` from `src/pages/<page-id>/<lang>/`
(`meta.json` + `content.html`) plus the shared partials in `src/partials/`.
English is served at the root. Run `python build.py` after editing any page
or partial.

## Status
